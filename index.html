Literature

  • TreeMap (Riley et al. 2021)
    • TreeMap links Forest Inventory and Analysis (FIA) data to LANDFIRE pixels. This allows for FIA data to be used spatially.
  • FuelMap (Riley, Grenfell, and Shaw 2023)
    • FuelMap is a second iteration of TreeMap that focuses on imputing better fuel loadings. FIA plots do not always record fuels. A second imputation imparts more accurate fuel values to the TreeMap plots from other FIA plots that have recorded fuel.
  • Kralicek (Kralicek, Sánchez Meador, and Rathbun 2018)
    • This paper provided the framework we are building on. Kralicek and her team imputed regeneration using Nearest Neighbor methods from plots in OR & WA. We have adapted it in many ways. Most obviously, we are trying a Random Forest approach that focuses on the area around the Okanogan and Wenatchee Nationa Forests. Early testing indicated that Random Forests produced more accurate results. The results of those tests are not shown here.
  • Random Forests (Breiman 2001)
    • Foundational paper on Random Forests.
  • Random Forest Imputation using yaImpute (Crookston and Finley 2008)
    • Package Documentation for the yaImpute package in R.
  • Ecoregions (Cleland et al. 2007)
    • FIA uses these ecological delineations. We are using them to subset the model into regions. This limits the species from being imputed from far away.
